# Instancia "pruebas" (Prism Launcher)

Copia de la instancia de pruebas del modpack mpxcosos.

- Minecraft 1.21.1 + NeoForge 21.1.265
- 204 mods (`minecraft/mods`), configs, resourcepacks, shaderpacks y el datapack `sin_bosses_naturales`
- Memoria configurada: 8 GB (MaxMemAlloc=8064). Ajustala en Prism si tu PC tiene menos RAM.

## Como usarla

1. Descarga el repo (boton verde "Code" > "Download ZIP") o clonalo.
2. Copia la carpeta `instancia-pruebas` dentro de la carpeta `instances` de Prism
   (en Windows: `%APPDATA%\PrismLauncher\instances`) y renombrala si quieres.
3. Abre Prism: la instancia aparece sola. Si Prism se queja de Java, en
   Editar > Ajustes > Java desmarca la ruta fija y deja que detecte Java 21.

## Que NO se subio

Mundos (`saves`), logs, capturas, crash-reports, cache y el cache de Diorama.
Son datos locales y pesan mucho; no hacen falta para jugar.
